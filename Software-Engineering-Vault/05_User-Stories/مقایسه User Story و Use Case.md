# مقایسه داستان کاربر (User Story) و مورد کاربرد (Use Case)

| معیار مقایسه | داستان کاربر (`User Story`) | مورد کاربرد (`Use Case`) |
| :--- | :--- | :--- |
| **رویکرد فرآیندی** | رایج در [[فرآیند توسعه چابک (Agile)|فرآیندهای چابک]] (`Scrum` / `XP`) | رایج در فرآیندهای ساختاریافته (مانند [[فرآیند یکپارچه منطقی (RUP)]]) |
| **سطح جزئیات و حجم** | بسیار کوتاه، خلاصه و قابل نوشتن روی یک کارت کوچک | مفصل، رسمی و شامل جریان اصلی و جریان‌های جایگزین |
| **هدف اصلی** | ایجاد زمینه برای گفت‌وگو و برنامه‌ریزی سریع اسپرینت | مستندسازی جامع تعاملات کاربر و سیستم پیش از ساخت |
| **زمان تکمیل جزئیات** | در حین گفت‌وگو با مشتری و تعریف [[معیارهای پذیرش و سه رکن (3Cs)]] | در فاز تحلیل و تشریح (`Elaboration`) پیش از پیاده‌سازی |
